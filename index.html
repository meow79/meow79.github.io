Проекты

Conv2d

Clash В разработке

Проект по свёртке изображения на ПЛИС. Пиксели поступают на вход по 1 за такт, поэтому реализация использует конвейер.

Отличительная особенность: в качесте языка используется Clash: код пишется на Haskell, а затем может быть транслирован в SystemVerilog или VHDL

Github

FPGA_learning

SystemVerilog cocotb

Здесь собраны модули с различной функциональностью, написанные на SystemVerilog с целью изучения языка. Также к большинству модулей прилаются тесты: как на SystemVerilog, так и на Python с фреймворком cocotb

Некоторые из модулей:
  • Счётчик на ПЛИС на сдвоенном семисегментном индикаторе
  • Одномерная свёртка
  • Сумматор для чисел, поступающих последовательно(по 1 биту за такт)
